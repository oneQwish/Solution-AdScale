# As-Is:
AdScale это SaaS-платформа, работающая с рекламодателями, функционал: работа с рекламными кампаниями, управление бюджетами и ставками, участие в RTB аукционах, показ рекламы пользователям сайтов и приложений, сбор аналитики и формирование отчетности для клиентов.  
### Обзор систем:
Гибридный монолит на C++ / Go / Python / Node, PostgreSQL, деплой производится вручную сразу в production. Компоненты приложения:
1. Рекламный сервер (С++, Go)
2. Сервер аукциона (C++)
3. Сервис выдачи (Node.js)
4. Сервис статистики (Python)
5. Финансовый сервис (Go)
6. Сервис аналитики (Python)
7. Рекламный кабинет (Node.js, JavaScript)

**Общая база данных PostgreSQL**.
**Кеша, очередей и контейнеризации нет.**

#### Внешние связи:
1. DSP-партнер (OpenRTB)
2. Платежный шлюз
3. Пользователи сайта/приложения

Система поддерживается командой из 35 человек, backend-, frontend- и DevOps-разработчики, тестировщики, дизайнеры, сотрудники службы поддержки, менеджмент.
**Нет выделенного SRE, техписателя, бизнес-аналитика.**

Текущее решение позволяет поддерживать штатную работу сервисов, но пиковые нагрузки приводят к деградации времени отклика (15 000 RPS в пике, P95 110–120 мс при требовании ≤100 мс, запаса по производительности нет).

### Узкие места системы:
Компоненты вызывают БД синхронно, это приводит к нарушению SLA <= 100 ms.
Запись в БД осуществляется без очередей/буфера, риск потери данных, конкуренция за ресурсы БД.
Модули аналитики берут данные тяжелыми запросами из единственной БД.
### Точка отказа системы:
**Общая база данных PostgreSQL** без read-replicas являет собой главную точку отказа системы. 
Компоненты конкурируют за ресурсы БД.
