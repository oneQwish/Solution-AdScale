# Task 1. Архитектурная диагностика и целевое видение

AdScale - SaaS-платформа цифровой рекламы, работающая на пределе производительности (15 000 RPS, P95 110-120 мс). Интеграция с крупным DSP-партнёром требует 18 000 RPS и ответа не более 80 мс через 3 месяца, 50 000 RPS и SLA 99,9% через год.

**Итог:** эволюция по паттерну Strangler Fig. API Gateway становится фасадом перед монолитом, первым выделяется Bidding Service, hot path отвязывается от базы данных через Redis, события показов и кликов уходят в Kafka. Через год - микросервисы с собственными базами, два региона.
